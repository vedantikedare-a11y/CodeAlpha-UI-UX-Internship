CodeAlpha UI/UX Internship Project

Project Overview

This project was created as part of my CodeAlpha UI/UX Design Internship. It focuses on designing a user-friendly restaurant ordering app interface.

Project Objective

The objective is to create a simple, attractive, and easy-to-use interface that allows users to explore restaurant menus, add food items to their cart, and view order confirmation.

Tools Used

- Figma
- GitHub
- UI/UX Design
- Wireframing
- Prototyping

Screens Designed

1. Login Screen
2. Home Screen
3. Restaurant Menu Screen
4. Cart Screen
5. Order Confirmation Screen

Design Process

Low-Fidelity Design

Basic wireframes were created to plan the layout, structure, and placement of interface elements.

High-Fidelity Design

Colour, typography, icons, and visual elements were added to create a polished interface.
